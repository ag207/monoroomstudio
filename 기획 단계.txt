기획 단계

사용자: 대학생
입력: 할 일, 마감일, 카테고리
행동: 체크박스를 눌러 3가지 결과 중 한 가지 선택
결과: 완료, 미완료, 다음날로 미루기 
형태: 안드로이드 위젯
레퍼런스: 

뜨개질 어시스턴트
일기 토픽 추천
인테리어 시큘레이터

(사용자)는 (상황)에서 (문제)를 겪고 있으며, 그결과 (손실, 불편)이 발생한다
(사용자)가 (문제)를 해결하기 위해 (핵심 행동)을 하면 (핵심 결과)를 얻는 서비스

같은 문제 상황이라도 접근 방식이 여러가지일 수 있음
실제 문제라면 사용자는 이미 어떤 방식으로든 해결하고 있음

프론트엔드- 사용자가보고 누르는 화면
백엔드- 요청을 처리
데이터베이스- 다시 쓸 데이터 보관
API-다른 서비스 기능 연결
